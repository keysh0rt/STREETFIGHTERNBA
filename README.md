# NBA STREET FIGHTER — Blacktop Edition

A mobile-first browser game build with a local CPU fight loop, touch controls, roster selection, story ladder, tournament progression, custom player identity, local career save, upgrade shop, cosmetics store, difficulty setting, and installable PWA files.

## Play / test
1. Extract this folder.
2. Host the folder on any static HTTPS host (GitHub Pages, Netlify, Cloudflare Pages, etc.).
3. Open `index.html` from the hosted URL on iPhone Safari.
4. Use Share → Add to Home Screen to install.
5. Landscape is recommended for fighting. Internet is only required for first visit / hosting; gameplay and local saves run in-browser.

## Controls
- Touch: left virtual stick; PUNCH, KICK, GUARD, DODGE, SPECIAL buttons.
- Keyboard: arrows or WASD to move; J punch; K kick; L guard; I dodge; U special.

## Honest scope
This is a substantial **local playable game prototype**, not yet a finished commercial game. Character renderings are original 2D canvas-drawn fighters rather than photorealistic sprite assets. Story and tournament progression are playable against CPU. Crew Wars has a lineup/planning screen but not team combat. Online is a roadmap screen; real online play requires a server and matchmaking. The game uses localStorage, not cloud accounts. The cover art is menu artwork, not a gameplay sprite sheet. Replace the drawn fighters with properly licensed, production-quality 2D sprite sheets when those are ready.
